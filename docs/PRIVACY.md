# 隐私说明

PathKeeper 是一个完全本地运行的桌面工具。这份文档列出具体的数据边界，方便你审计。

## 不收集什么

- 不收集账号、邮箱、设备指纹或使用统计。
- 不发送文件内容、路径、项目名或迁移历史。
- 不包含崩溃上报、遥测 SDK、广告 SDK 或自动更新检查。
- 不发起任何 Web 请求。生产构建会拒绝所有 `http(s)` / `ws(s)` 请求；渲染层没有加载
  远程字体、图片、脚本或样式。

## 保存在本机什么位置

| 数据 | 位置 |
| --- | --- |
| 项目列表、设置、规则、迁移历史 | `%APPDATA%\PathKeeper\pathkeeper.sqlite` |
| 修改前的文件备份 | `<项目根>\.pathkeeper-backup\<时间戳>-<随机串>\` |
| 备份清单 | 上述目录内的 `manifest.json` |
| 应用日志 | 默认不写日志文件；终端启动时只输出到控制台 |

SQLite 数据库包含项目根路径、迁移的旧/新相对路径、被修改文件列表和 hash。它不包含文件
全文。

## 备份里有什么

每次应用修改时，PathKeeper 会把受影响文件的**原始内容完整复制**到项目内的备份目录，
并在 `manifest.json` 中记录迁移信息、文件列表、原始 hash 和处理时间。备份可由你在设置
中心删除，也可以直接在资源管理器中删除。卸载应用不会自动删除这些项目内备份。

## 如何在应用内清除数据

- 设置中心 → 备份管理：删除某次备份（删除后该迁移无法回滚）。
- 迁移历史：删除单条记录（备份会保留，直到在备份管理中删除）。
- 项目：移除项目只删除应用数据库中的记录，不删除项目文件与 `.pathkeeper-backup`。

## 完全清除

退出 PathKeeper 后删除：

```text
%APPDATA%\PathKeeper
```

以及各项目中的 `.pathkeeper-backup` 目录。PathKeeper 不会写入其他位置（除系统文件选择器
明确选择的项目根与 CSV 导出路径）。

## 验证无网络

- 打包版本的主进程在创建窗口前安装请求拦截器，取消所有外部协议请求。
- 界面资源全部来自应用包内（`file://`），不引用 CDN。
- 你可以在 `src/main/index.ts` 的 `installLocalOnlyNetworkPolicy` 查看实现。
